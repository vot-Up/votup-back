# ADR-002: Module-Based Admin Organization

## Status
Accepted

## Date
2026-05-16

## Context
The project has two empty admin.py files (core/admin.py, account/admin.py). With 8+ ModelAdmins, 4 inlines, and 3 custom actions, a single file per app would become unwieldy (300+ lines). The sidebar is organized by domain (Votação, Pessoas, Chapas, Sistema), suggesting a natural code organization.

## Decision
Organize admin as a Python module per app: `core/admin/__init__.py` + domain-specific files (`voting.py`, `people.py`, `plates.py`). Account admin remains in `account/admin.py` since it has only one ModelAdmin (User).

## Alternatives Considered

### Alternative 1: Single File Per App
- **Description**: All core admin classes in `core/admin.py`
- **Pros**: Simple, conventional Django pattern
- **Cons**: 300+ lines in one file, hard to navigate, doesn't align with domain sidebar structure
- **Why rejected**: Code organization should reflect the domain structure users see in the sidebar

### Alternative 2: Separate Django App Per Domain
- **Description**: Create `core/admin_voting/`, `core/admin_people/` apps
- **Pros**: Full app isolation
- **Cons**: Over-engineering, adds unnecessary INSTALLED_APPS entries, models still live in core
- **Why rejected**: YAGNI — a module package is sufficient without full app overhead

## Consequences

### Positive
- Each file maps to a sidebar section — easy to find and maintain
- `__init__.py` re-exports for clean imports
- Account admin stays simple (single file)

### Negative
- Slight deviation from Django convention (most projects use single admin.py)
- Need to ensure `__init__.py` properly imports all admin classes so Django discovers them

### Risks
- Django admin autodiscovery expects `admin.py` by default — mitigated by using `admin/__init__.py` which autodiscovery also checks

## Implementation Notes
- Delete `core/admin.py`, create `core/admin/` package
- `core/admin/__init__.py` imports from domain modules
- Django's autodiscovery finds `core/admin/__init__.py` automatically
